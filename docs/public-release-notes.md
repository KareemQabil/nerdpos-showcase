# NerdPOS Public Release Notes

This showcase repo is a public-safe release layer, not a raw source-code publication.

## Included publicly

- real screenshots from a safe frontend-only copy
- workflow diagrams
- product framing and module explanation
- public-safe narrative about what the surfaces prove

## Excluded intentionally

- backend code
- credentials or environment setup
- customer data
- business-specific logic or integrations

## Why this release format is used

For business software, public proof is more credible when it is:

- specific
- bounded
- evidence-based
- honest about what is private

That is the purpose of this repo.
